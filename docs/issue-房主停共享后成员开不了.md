## 现象
房主开始屏幕共享 → 房主停止 → **其他成员**（Linux 版）点"共享屏幕"：按钮可点，但共享起不来 ✗。房主可重新开；**Windows 版同场景正常** ✓。

## 环境
QQ 3.2.34-53644（Linux，niri 原生 Wayland）+ linuxqq-wayland-fix 0.2.15.test2-1

## 复现
1. 多人通话中，房主开始屏幕共享
2. 房主停止共享
3. 另一名 Linux 成员点"共享屏幕" → 共享无法建立（按钮可点，非禁用）

## 已确认
- 房主可再次共享 ✓；Windows 版成员正常 ✓
- 失败的成员**重启 QQ 后仍失败** ✗（非客户端本地状态残留）
- 按钮**不是灰色**，可点击 ✗
